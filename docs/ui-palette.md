# UI colour palette

Carried over from the legacy gpui prototype (`src/colour_palette.rs` in the
first commit). Use it for any UI: the stretch-goal local status page, and the
demo slides.

| Role | Name | Hex |
|---|---|---|
| Background | Deep Space Blue | `#1A2749` |
| Primary accent | Cosmic Purple | `#5D3FD3` |
| Text | Alabaster Grey | `#E6E6E6` |
| Highlight | Nebula Teal | `#2DE1C2` |
| Alert | (orange) | `#FF6B35` |

The prototype also had a comment pointing to an alternative coolors palette
(`#805D93 #F49FBC #FFD3BA #9EBD6E #169873`). The enum colours above are the
chosen ones.
